# 스크리너 사용법

`screener.py`는 강고양이 매매법에서 데이터로 확인할 수 있는 조건을 기준으로 바이낸스 USDⓈ-M 선물 종목을 걸러 줘요. 관심 목록 후보를 뽑는 도구이고, 매수·매도 추천이 아니에요.

## 준비

- Python 3.9 이상만 있으면 돼요. 추가 설치할 패키지는 없어요.
- Windows라면 [python.org](https://www.python.org/downloads/)에서 설치할 때 "Add python.exe to PATH"를 체크하세요.

## 실행

저장소 폴더에서:

```
python tools/screener.py
```

Windows에서는 `screener.py`와 같은 폴더에 둔 `run_screener.bat`을 더블클릭해도 돼요.

- 바이낸스 실시간 API로 지금 시세를 받아요. 한국에서는 바로 돼요.
- 1~3분쯤 걸리고, 결과는 화면과 `screener_result.csv`에 나와요. CSV는 엑셀로 열면 돼요.

자주 쓰는 옵션:

| 옵션 | 뜻 | 기본값 |
| --- | --- | --- |
| `--vol 350` | 하루 거래대금 폭발 기준(M USDT) | 300 |
| `--days 30` | 폭발을 세는 최근 일수 | 30 |
| `--min-bursts 2` | 최근 폭발 최소 횟수. 2로 하면 하루짜리 폭발을 뺌 | 1 |
| `--include-kr` | 업비트·빗썸 상장 코인도 보기 | 제외 |
| `--include-big` | 원래 거래량이 큰 코인도 보기 | 제외 |
| `--source archive --asof 2026-03-17` | 공개 아카이브로 과거 날짜 기준 실행 | 실시간 API |
| `--out 파일.csv` | CSV 저장 위치 | `screener_result.csv` |

바이낸스 API가 막힌 곳(미국 서버 등)에서는 `--source archive`를 쓰세요. 이틀 전 데이터까지만 있고, 처음 실행은 파일을 많이 받아서 10분 정도 걸려요. 받은 파일은 `tools/.cache`에 저장돼서 다음부터 빨라요.

## 거르는 조건

1. **대상:** 거래 중인 USDT 무기한 선물이에요. 주식·원자재 선물, BTC·ETH 같은 대형 코인, 스테이블은 빼요.
2. **국내 상장 제외:** 업비트의 원화·BTC·USDT 마켓과 빗썸의 원화·BTC 마켓에 있는 코인은 빼요.
3. **거래량 폭발:** 최근 30일 안에 하루 거래대금이 기준(300M)을 넘은 날이 있어야 해요.
4. **새로 터진 코인:** 최근 60일 안의 첫 폭발 전 30일 동안 거래대금 중간값이 기준의 3분의 1보다 작아야 해요. 원래 늘 거래량이 큰 코인은 빼요.

## 결과 열

| 열 | 뜻 |
| --- | --- |
| 최근 폭발 | 최근 30일 동안 기준을 넘은 날 수 |
| 첫 폭발 / 마지막 폭발 | 최근 60일 안의 첫 폭발일과 가장 최근 폭발일 |
| 폭발 전 중간값 | 첫 폭발 전 30일 동안의 하루 거래대금 중간값. 작을수록 조용하다가 터진 코인 |
| 바닥 대비 | 첫 폭발 전 30일 최저 종가 대비 지금 가격 |
| 고점 대비 | 첫 폭발 뒤 최고 종가 대비 지금 가격 |
| 10일 박스 위치 | 최근 10일 종가 범위에서 지금 위치. 100%면 박스 맨 위 |
| 7일 수익률 | 최근 7일 수익률. BTC 7일 수익률과 비교해 보세요 |
| 4h 양봉/12, 4h 저점상승/12 | 최근 4시간봉 12개 중 양봉 수와, 저점이 직전 봉보다 높은 봉 수 |

메모 열에 붙는 표시:

- **폭발 1번뿐:** 하루짜리 폭발이에요. 지난 1년 데이터로는 이런 경우 3배 간 비율이 4%였어요.
- **바닥 대비 N배 · 이미 크게 오름:** 매집형 진입 자리는 지났어요. 대장 추종형으로만 볼 수 있어요.
- **폭발 후 최대 낙폭:** 첫 폭발 뒤 가장 크게 빠졌던 폭이에요. 사이렌도 -65%가 있었으니 이것만으로 거르지는 마세요.
- **25% 넘는 꼬리 N일(무빙 거침):** 최근 30일 중 일봉 꼬리가 25%를 넘은 날 수예요. 강고양이님이 피하는 "다 내리고 말아 올리는" 일봉 모양을 찾기 위한 참고용이에요.
- **BTC 하락 중 버팀:** 최근 7일 BTC가 3% 넘게 빠지는 동안 이 코인은 BTC보다 5%p 넘게 잘 버텼어요.
- **10일 박스 상단 / 폭발 후 최고가 부근:** 돌파를 지켜볼 자리예요.

## 검증

공개 아카이브로 강고양이님이 실제로 진입한 날짜를 넣어 돌려 봤어요(폭발 기준 300M).

| 기준일 | 실제 매매 | 결과 |
| --- | --- | --- |
| 2026-03-17 | 사이렌 진입 직전 | 13개 중 SIREN 포함 (폭발 6회, 폭발 후 최고가 부근) |
| 2026-06-21 | SYN 진입(6/22 01시 KST) 직전 | 22개 중 SYN 포함 (폭발 1회, BTC 하락 중 버팀) |
| 2026-09-01 | AKE 재진입 | 15개 중 AKE 포함 (바닥 대비 46배, 이미 크게 오름) |

같은 날 목록에는 나중에 무너진 종목도 많이 섞여 있었어요. 이 도구는 후보를 좁혀 줄 뿐이고, 그중 무엇을 고르는지가 강고양이님 판단의 몫이에요.

아카이브 방식에서는 종목 종류 정보가 없어서 알려진 주식·ETF 선물만 이름으로 빼요. 새로 상장된 주식 선물이 섞일 수 있어요. 실시간 방식은 바이낸스 종목 정보로 자동으로 걸러져요.
